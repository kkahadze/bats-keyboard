US labels show physical positions. Green keys differ from Base; ∅ means no output and — means unmapped. On a phone, swipe to see the full keyboard.

From preview to everyday typing.

  1. Download the latest ZIP and unzip it.
  2. In Finder, choose Go → Go to Folder and open ~/Library/Keyboard Layouts/. Create the folder if needed, then copy Bats.bundle into it.
  3. Log out and back in. Open System Settings → Keyboard → Text Input → Edit, then add Bats as an input source.
